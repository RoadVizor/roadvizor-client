# 🛣️ RoadVizor — Pipeline de Dados e Monitorização

O repositório do **RoadVizor** contém a infraestrutura completa para a captura, limpeza e enriquecimento de dados de telemetria de servidores de rodovias. O fluxo de processamento utiliza a arquitetura Medallion (Bronze, Silver e Gold) na plataforma AWS (Amazon S3), apoiado por uma base de dados MySQL para gestão de metadados e regras de alerta.

---
